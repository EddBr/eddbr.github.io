A language model is a policy

A language model gives a probability to every possible next token, given the text so far. Read that as RL: the text so far is the state, the next token is the action, and a finished reply is an episode. Everything from Lessons 70 to 84 then applies to it.

Each episode samples a sentence at $\tau = 1$, scores it, and nudges the log-probability of every token in it by $\alpha(R - b)$, with $b$ the average reward so far (Lessons 73 and 74). $\alpha = 0.2$.

The maths

Given a prompt $x$, a language model with parameters $\theta$ generates a reply $y = (y_1, \dots, y_T)$ one token at a time. The probability of the whole reply is the product of the per-token probabilities:

$$\begin{aligned} \pi_\theta(y \mid x) &= \prod_{t=1}^{T} \pi_\theta(y_t \mid x, y_{<t}) \\ \log \pi_\theta(y \mid x) &= \sum_{t=1}^{T} \log \pi_\theta(y_t \mid x, y_{<t}) \end{aligned}$$

$y_{<t}$ is the tokens before position $t$. Multiplying many probabilities quickly underflows, so models work with the sum of logs. The line under the buttons shows it for your sentence.

As an MDP.

$$\begin{aligned} &s_t = (x, y_{<t}), \qquad a_t = y_t, \qquad s_{t+1} = (x, y_{\le t}), \\ &R = r(x, y) \text{ at the end}, \qquad \gamma = 1 \end{aligned}$$

The state is everything written so far, an action is one token, and the transition is deterministic: append the token. The reward usually arrives only when the reply is finished, so the return of every step is $G_t = r(x, y)$.

The policy. The network outputs a score (logit) $z_v$ for each token $v$ in the vocabulary, and a softmax with temperature $\tau$ turns them into probabilities:

$$\pi_\theta(v \mid s_t) = \frac{e^{z_v(s_t)/\tau}}{\sum_{u} e^{z_u(s_t)/\tau}}$$

$\tau < 1$ sharpens the distribution towards the top token; $\tau > 1$ flattens it. This toy's logits depend only on the last token. A real model's depend on the whole of $s_t$.

The gradient. REINFORCE with a baseline (Lessons 73 and 74), applied to whole replies:

$$\nabla_\theta J(\theta) = \mathbb{E}_{y \sim \pi_\theta(\cdot \mid x)}\Big[\big(r(x, y) - b\big) \sum_{t=1}^{T} \nabla_\theta \log \pi_\theta(y_t \mid s_t)\Big]$$

Every token in a good reply is made more likely; every token in a bad one less likely. The hard part is scale: a vocabulary of $|\mathcal{V}| \approx 10^5$ tokens and replies of hundreds of tokens give $|\mathcal{V}|^T$ possible episodes.

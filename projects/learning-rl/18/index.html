Markov decision processes

A Markov decision process (MDP) is a Markov chain (Lesson 16) where an agent picks an action in each state, and the action changes where the chain goes next and what reward it pays. Outcomes can be random. One function, $p(s', r \mid s, a)$, describes the whole environment.

The floor is icy. A move goes where you meant with probability $1 - \text{slip}$ and slides to either side with probability $\text{slip}/2$ each. Moving into a wall or the edge leaves you where you are. Each move costs $-1$, landing on 🏁 pays $+10$ and landing in 🕳️ costs $-10$. Click any cell to put the robot there.

The maths

At each step $t$ the agent sees state $S_t$, picks action $A_t$, and the environment returns a reward $R_{t+1}$ and a next state $S_{t+1}$. The dynamics of the MDP are the probabilities

$$\begin{aligned} &p(s', r \mid s, a) \\ &\quad = P(S_{t+1} = s',\ R_{t+1} = r \mid S_t = s,\ A_t = a) \end{aligned}$$

for every state $s$, action $a$, next state $s'$ and reward $r$. This is the table in the interactive. It depends only on $s$ and $a$, never on earlier steps: the Markov property from Lesson 15, now with actions.

For each $s$ and $a$ the outcomes form a probability distribution:

$$\sum_{s'} \sum_{r} p(s', r \mid s, a) = 1$$

Two quantities used constantly later follow from $p$ by summing. The state-transition probability ignores the reward:

$$p(s' \mid s, a) = \sum_r p(s', r \mid s, a)$$

The expected reward for an action in a state averages it:

$$\begin{aligned} r(s, a) &= \mathbb{E}[R_{t+1} \mid S_t = s, A_t = a] \\ &= \sum_{r} r \sum_{s'} p(s', r \mid s, a) \end{aligned}$$

This is the "expected reward" line under the table.

An MDP is the states $\mathcal{S}$, the actions $\mathcal{A}$, the dynamics $p$, and a discount $\gamma$ (Lesson 4). With one state it is a bandit (Lessons 5 to 13). When the action does not affect the next state it is a contextual bandit (Lesson 14). The new thing here is that actions have consequences for the future: a move that costs $-1$ now can set up $+10$ later.

Notice a flaw in this world: nothing stops the robot sitting on 🏁 and bumping into the edge to collect $+10$ again and again. Lesson 19 fixes that with terminal states.

Rewards define the goal

The agent never learns what you want. It only sees the rewards. Change the rewards and the best behaviour changes with them.

← Coin (1 step)
Stay put
Gem → (4 steps)

The maths

Each option produces a sequence of rewards. The agent picks the one with the largest return $G = R_1 + \dots + R_T$. With a reward of $s$ per step, walking to the gem gives

$$\begin{aligned} G_{\text{gem}} &= \underbrace{s + s + s}_{\text{walking}} + \underbrace{(s + \text{gem})}_{\text{arriving}} \\ &= 4s + \text{gem} \end{aligned}$$

and the coin gives $G_{\text{coin}} = s + \text{coin}$. Set them equal to find where the choice flips.

This is the reward hypothesis: every goal can be described as maximising the expected return. The designer says what is good through the rewards, never how to achieve it.

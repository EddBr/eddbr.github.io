Generalised advantage estimation

The one-step TD error is a steady but biased advantage estimate when the critic is wrong. The full return minus a baseline is unbiased but noisy. GAE adds up all future TD errors with weights that shrink by $\gamma\lambda$ per step, so a single knob $\lambda$ slides between the two, exactly as λ-returns did for values in Lesson 57.

The bias–variance trade-off

The maths

Write $\delta_t = R_{t+1} + \gamma \hat v(S_{t+1}) - \hat v(S_t)$ for the critic's TD error, with $\delta_t = 0$ once the episode has ended. Summing the first $k$ of them with discounts gives the $k$-step advantage estimate; the $\hat v$ terms telescope as in Lesson 75:

$$\hat A^{(k)}_t = \sum_{l=0}^{k-1} \gamma^l \delta_{t+l} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{k-1} R_{t+k} + \gamma^k \hat v(S_{t+k}) - \hat v(S_t)$$

It is the $k$-step return of Lesson 56 minus the baseline $\hat v(S_t)$. Small $k$ leans on the critic; large $k$ leans on real rewards.

GAE (Schulman et al., 2016) averages all of them with weights $(1-\lambda)\lambda^{k-1}$, as the λ-return does:

$$\hat A^{\text{GAE}(\gamma,\lambda)}_t = (1-\lambda) \sum_{k=1}^{\infty} \lambda^{k-1} \hat A^{(k)}_t = \sum_{l=0}^{\infty} (\gamma\lambda)^l\, \delta_{t+l}$$

The second form follows by collecting terms: $\delta_{t+l}$ appears in every $\hat A^{(k)}_t$ with $k > l$, so its weight is $\gamma^l (1-\lambda)\sum_{k > l} \lambda^{k-1} = \gamma^l \lambda^l$. Equivalently $\hat A_t = G^\lambda_t - \hat v(S_t)$, the λ-return minus the baseline.

The two ends of the slider:

$$\lambda = 0:\ \hat A_t = \delta_t, \qquad \lambda = 1:\ \hat A_t = \sum_{l=0}^{\infty} \gamma^l \delta_{t+l} = G_t - \hat v(S_t)$$

At $\lambda = 1$ the estimate is unbiased however wrong the critic is (the $-\hat v(S_t)$ term is a baseline, which adds no bias to the policy gradient, Lesson 74). At $\lambda = 0$ it is biased unless $\hat v = v_\pi$, but it has the least variance. In between, each extra step of real reward cuts bias and adds noise. Values like $\lambda = 0.95$ with $\gamma = 0.99$ are common in practice.

Computing it. One backward pass over the episode, starting from $\hat A_T = 0$:

$$\hat A_t = \delta_t + \gamma\lambda\, \hat A_{t+1}$$

That is how the table above fills its $\hat A_t$ column, and how PPO implementations (Lessons 80 onwards) compute advantages.

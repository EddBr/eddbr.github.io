Generalisation

With shared features, an update to one state changes the estimates of every state that shares those features. That is how an agent can value states it has never visited. The features decide how far each update spreads.

The state is a number between 0 and 1. Each feature is an interval and is 1 for states inside it (coarse coding, S&B §9.5.3). Click or drag on the chart to set a target there: the estimate at that point moves halfway to it.

The maths

For a linear estimate, one update at state $s$ with error $\delta = U - \hat v(s,\mathbf{w})$ is $\Delta\mathbf{w} = \alpha\,\delta\,\mathbf{x}(s)$. Any other state $s'$ then changes by

$$\Delta \hat v(s') = \Delta\mathbf{w}^\top \mathbf{x}(s') = \alpha\,\delta\;\mathbf{x}(s)^\top \mathbf{x}(s').$$

States move in proportion to how much their features overlap with $s$. With no overlap, they do not move at all.

With binary features, $\mathbf{x}(s)^\top\mathbf{x}(s')$ counts the features the two states share. If every state has exactly $n$ active features and $\alpha = f/n$:

$$\Delta \hat v(s') = f\,\delta \cdot \frac{\text{shared features}}{n}.$$

At $s$ itself all $n$ are shared, so the estimate moves a fraction $f$ of the way to the target (here $f = 0.5$). For intervals of width $W$ packed evenly, the shared fraction falls off linearly with distance, which is the triangle you see:

$$\frac{\text{shared}}{n} \approx \max\!\Big(0,\; 1 - \frac{|s - s'|}{W}\Big).$$

Wide features generalise far and learn the rough shape quickly. Narrow features generalise little and need samples everywhere. In S&B Example 9.3 the final functions end up similar: width mostly changes how learning spreads early on, while the fineness of the final answer depends on how many features there are.

Tile coding (S&B §9.5.4) is the practical version. It uses $n$ grids ("tilings"), each offset slightly from the others. Each tiling has exactly one active tile, so exactly $n$ features are active. With $\alpha = 1/n$ an update moves the estimate all the way to the target, and with $\alpha = 1/(10n)$ it moves a tenth of the way.

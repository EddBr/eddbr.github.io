The maths

The six drill formulas, with the lesson that derives each one.

$$G_t = \sum_{k=0}^{T-t-1} \gamma^k R_{t+k+1}$$

Return (Lesson 4): later rewards count for less, by a factor $\gamma$ per step.

$$Q_{n+1} = Q_n + \alpha\,[R_n - Q_n]$$

Incremental update (Lessons 6–7): move a fraction $\alpha$ of the way from the old estimate to the new reward.

$$A_t = \arg\max_a \Big[Q_t(a) + c\sqrt{\frac{\ln t}{N_t(a)}}\,\Big]$$

UCB (Lesson 9): add a bonus that is large for arms tried rarely, relative to the total number of steps $t$.

$$v_\pi(s) = \sum_a \pi(a \mid s)\, q_\pi(s, a)$$

State value from action values (Lesson 23): average the action values with the policy's probabilities.

$$v_\pi(s) = \sum_a \pi(a \mid s) \sum_{s', r} p(s', r \mid s, a)\big[r + \gamma\, v_\pi(s')\big]$$

Bellman expectation (Lesson 26): average reward now plus discounted value next, over everything that can happen.

$$\rho_{t:T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}$$

Importance sampling ratio (Lesson 39): how much more (or less) likely the target policy $\pi$ was than the behaviour policy $b$ to take the actions that were taken. The environment's probabilities cancel.

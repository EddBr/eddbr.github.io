Baselines

REINFORCE scales each push by the raw return. If every return is large and positive, every action gets pushed up, and only the small differences between them carry information. Subtracting a baseline $b(s)$ from the return leaves the expected gradient unchanged and can shrink its variance dramatically.

REINFORCE with a baseline

The short corridor from Lessons 70 and 73. Plain REINFORCE ($\alpha = 2^{-13}$) against REINFORCE with a learned baseline ($\alpha^{\boldsymbol\theta} = 2^{-9}$, $\alpha^{\mathbf w} = 2^{-6}$), 50 runs of 1000 episodes (S&B Figure 13.2). The agent cannot tell the states apart, so the baseline is a single learned number $\hat v = w$.

The baseline lets the policy use a step size 16 times larger without blowing up, because each update is no longer dominated by "every action was bad".

The maths

The policy gradient theorem holds with any baseline $b(s)$ that does not depend on the action (S&B eq. 13.10):

$$\nabla J(\boldsymbol\theta) \propto \sum_s \mu(s) \sum_a \big(q_\pi(s,a) - b(s)\big)\, \nabla \pi(a \mid s, \boldsymbol\theta)$$

The extra term is zero, because the probabilities always sum to 1:

$$\sum_a b(s)\, \nabla \pi(a \mid s, \boldsymbol\theta) = b(s)\, \nabla \sum_a \pi(a \mid s, \boldsymbol\theta) = b(s)\, \nabla 1 = 0$$

So the baseline adds nothing to the expected gradient. Following the steps of Lesson 73 gives REINFORCE with baseline (eq. 13.11):

$$\boldsymbol\theta_{t+1} = \boldsymbol\theta_t + \alpha \big(G_t - b(S_t)\big)\, \nabla \ln \pi(A_t \mid S_t, \boldsymbol\theta_t)$$

The push is now "how much better than the baseline", which can be negative or positive.

Variance. For one state, a sample is $\hat g = (R - b)\,\nabla\ln\pi(A)$. Its mean does not depend on $b$, so its variance is smallest where $\mathbb{E}\big[\lVert\hat g\rVert^2\big]$ is smallest. That is a parabola in $b$, minimised at

$$b^* = \frac{\mathbb{E}\big[R\, \lVert\nabla\ln\pi(A)\rVert^2\big]}{\mathbb{E}\big[\lVert\nabla\ln\pi(A)\rVert^2\big]}$$

This is an average reward weighted by the size of each action's gradient. It is usually close to the plain average reward, which is why "Set b to the average reward" lands near the bottom of the curve.

A learned baseline. The natural choice is a state-value estimate $\hat v(S_t, \mathbf w)$, learned by Monte Carlo from the same returns (S&B §13.4):

$$\begin{aligned} \delta &\leftarrow G_t - \hat v(S_t, \mathbf w) \\ \mathbf w &\leftarrow \mathbf w + \alpha^{\mathbf w}\, \delta\, \nabla \hat v(S_t, \mathbf w) \\ \boldsymbol\theta &\leftarrow \boldsymbol\theta + \alpha^{\boldsymbol\theta}\, \gamma^t\, \delta\, \nabla \ln \pi(A_t \mid S_t, \boldsymbol\theta) \end{aligned}$$

$\delta$ says whether the episode went better or worse than this state usually goes. Lesson 75 asks what happens when $\hat v$ is used for more than a baseline.

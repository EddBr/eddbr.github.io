Goodhart's law

"When a measure becomes a target, it ceases to be a good measure." A reward model (Lesson 87) is a measure fitted on what the model already does. Optimise hard against it and the policy moves to places the reward model never saw, where it is wrong. The proxy score keeps rising while the true score peaks and falls.

One feature of a response: $x$, how much longer it is than usual (in standard deviations). The true quality $r^*(x) = x - x^2/4$ rises with length up to $x = 2$, then padding makes answers worse. The reference model writes $x \sim \mathcal{N}(0, 1)$. People rate 40 of its answers (grey dots) and a straight-line reward model $\hat r(x) = w x + b$ is fitted to them.

The maths

The reward model is fitted by least squares on answers from the reference. For $x \sim \mathcal{N}(0,1)$ the best straight line through $r^*(x) = x - x^2/4$ has slope

$$\begin{aligned} w &= \frac{\operatorname{Cov}(x, r^*(x))}{\operatorname{Var}(x)} \\ &= \frac{\mathbb{E}[x^2] - \tfrac14 \mathbb{E}[x^3]}{1} = 1 \end{aligned}$$

because $\mathbb{E}[x^3] = 0$. Near the data the line is a fine fit. It says "longer is always better", which is only true for $x < 2$.

For a policy $\pi = \mathcal{N}(\mu, 1)$, using $\mathbb{E}_\pi[x^2] = \mu^2 + 1$:

$$\mathbb{E}_\pi[\hat r] = w\mu + b, \qquad \mathbb{E}_\pi[r^*] = \mu - \frac{\mu^2 + 1}{4}$$

The proxy grows forever. The true score peaks at $\mu = 2$ and is back where it started at $\mu = 4$. How far the policy has moved is measured by the KL divergence (Lesson 81), which for two unit-variance Gaussians is

$$\mathrm{KL}\big(\mathcal{N}(\mu,1) \,\|\, \mathcal{N}(0,1)\big) = \frac{\mu^2}{2}$$

With the KL penalty of Lesson 88, the policy maximises $w\mu + b - \beta\mu^2/2$. Setting the derivative $w - \beta\mu$ to zero gives

$$\mu^\star = \frac{w}{\beta}$$

So $\beta$ decides how far the policy is allowed to chase the proxy. With $w = 1$, $\beta = 0.5$ stops exactly at the true peak. Too small and it overshoots into the region the reward model never saw.

Gao, Schulman and Hilton (2022) measured this with real language models, using a large "gold" reward model as the truth and smaller ones as proxies. Writing $d = \sqrt{\mathrm{KL}}$, the gold score under best-of-$n$ sampling fit $d(a - b\,d)$, and under RL fit $d(a - b \log d)$, for constants $a, b > 0$ (their paper calls them $\alpha$ and $\beta$; this $b$ is not the KL coefficient). Here, with $\mu = \sqrt{2}\,d$, the true score is $-\tfrac14 + d(\sqrt 2 - d/2)$: the same shape as their best-of-$n$ curve.

REINFORCE

Lessons 71 and 72 give the gradient as an average of $q_\pi(S_t, A_t)\,\nabla \ln \pi(A_t \mid S_t)$. REINFORCE replaces the unknown $q_\pi$ with the return that actually followed. Play a whole episode, then nudge every action taken by its log-probability gradient, scaled by its return.

Step size matters

Return per episode, averaged over 50 runs of 1000 episodes and smoothed over 10 episodes, for three step sizes (S&B Figure 13.1). The largest step size sometimes throws a run into a policy that almost never finishes, and those runs drag its average down. The smallest is safe but slow.

The maths

Start from the policy gradient theorem (Lesson 71) and apply the log trick (Lesson 72) to the sum over actions:

$$\begin{aligned} \nabla J(\boldsymbol\theta) &\propto \mathbb{E}_\pi\Big[\sum_a \pi(a \mid S_t, \boldsymbol\theta)\, q_\pi(S_t, a)\, \frac{\nabla \pi(a \mid S_t, \boldsymbol\theta)}{\pi(a \mid S_t, \boldsymbol\theta)}\Big] \\ &= \mathbb{E}_\pi\big[q_\pi(S_t, A_t)\, \nabla \ln \pi(A_t \mid S_t, \boldsymbol\theta)\big] \\ &= \mathbb{E}_\pi\big[G_t\, \nabla \ln \pi(A_t \mid S_t, \boldsymbol\theta)\big] \end{aligned}$$

The second line replaces the weighted sum over $a$ by the sampled action $A_t \sim \pi$. The third uses $\mathbb{E}_\pi[G_t \mid S_t, A_t] = q_\pi(S_t, A_t)$. Everything inside the last expectation is observed, so each time step gives a sample. The REINFORCE update (S&B eq. 13.8) is

$$\boldsymbol\theta_{t+1} = \boldsymbol\theta_t + \alpha\, G_t\, \nabla \ln \pi(A_t \mid S_t, \boldsymbol\theta_t)$$

An action followed by a high return has its probability raised, in proportion to the return. $G_t$ uses only the rewards after time $t$: an action cannot be credited for rewards that came before it.

REINFORCE (episodic, S&B §13.3)

Loop for each episode:

Generate $S_0, A_0, R_1, \dots, S_{T-1}, A_{T-1}, R_T$ following $\pi(\cdot \mid \cdot, \boldsymbol\theta)$

Loop for each step $t = 0, 1, \dots, T-1$:

$G \leftarrow \sum_{k=t+1}^{T} \gamma^{k-t-1} R_k$

$\boldsymbol\theta \leftarrow \boldsymbol\theta + \alpha\, \gamma^t\, G\, \nabla \ln \pi(A_t \mid S_t, \boldsymbol\theta)$

The corridor has $\gamma = 1$, so $G_t = -(T - t)$ and $\gamma^t = 1$. With the features from Lesson 70 and $p = \pi(\text{right})$, eq. 13.9 gives

$$\nabla \ln \pi(\text{right}) = \begin{pmatrix} 1 - p \\ -(1 - p) \end{pmatrix}, \qquad \nabla \ln \pi(\text{left}) = \begin{pmatrix} -p \\ p \end{pmatrix}$$

Every return here is negative, so every action taken gets pushed down. Actions in short episodes get pushed down less, and on average the push equals $\nabla J$. That averaging needs many episodes, which is why REINFORCE is slow and needs a small $\alpha$. Too large and one long unlucky episode knocks the policy far off course.

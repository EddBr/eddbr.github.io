Batch updating

Suppose the data is fixed: eight episodes and no more. Replay them over and over, updating each time, until the values stop changing. Monte Carlo and TD both settle, but on different answers. The difference shows what each method estimates.

Each sweep replays all eight episodes, adds up every increment $\alpha\,[\text{target} - V]$ for each state with $\alpha = 0.02$, and then applies the totals at once (S&B §6.3). Values start at 0.5.

The maths

Batch Monte Carlo converges to the average return observed from each state. That minimises the squared error on the data:

$$V_\text{MC}(s) = \frac{1}{N(s)} \sum_{\text{visits to } s} G_t$$

With the book's data, A was visited once and its return was $0$, so $V_\text{MC}(\text{A}) = 0$.

Batch TD(0) converges to something else. Fit the most likely Markov model to the data: transition probabilities $\hat p(s' \mid s) = N(s \to s')/N(s)$ and mean rewards $\hat r(s \to s')$. Then solve that model's Bellman equation exactly:

$$V_\text{TD}(s) = \sum_{s'} \hat p(s' \mid s)\,\big[\hat r(s \to s') + V_\text{TD}(s')\big]$$

This is the certainty-equivalence estimate: the right answer if the fitted model were exactly true.

For the book's data, every transition out of A went to B with reward $0$, and B ended with reward 1 in six of eight episodes:

$$V_\text{TD}(\text{B}) = \tfrac68 = 0.75, \qquad V_\text{TD}(\text{A}) = 0 + V_\text{TD}(\text{B}) = 0.75$$

Both methods agree on B. They disagree on A because MC trusts the single return seen from A, while TD uses everything known about B.

If the process is Markov, the TD answer should predict new data better. That is why batch TD beats batch MC on the random walk above. Computing the certainty-equivalence estimate directly needs memory for every pair of states and roughly $n^3$ steps to solve for $n$ states. TD reaches it using memory for one number per state.

Step sizes and moving targets

In Lessons 5 and 6 each lever's true value $q_*$ never changed, so averaging every reward ever seen was the best estimate. If $q_*$ drifts, old rewards describe a lever that no longer exists, and the average is held back by them. A constant step size $\alpha$ forgets old rewards at a steady rate, so the estimate keeps up.

One drifting lever, two estimates

There is a single lever. Every step, its true value $q_*$ wanders a little at random, and pulling it pays $q_*$ plus noise. Two estimates watch exactly the same rewards and differ only in step size:

  • True $q_*$ (dashed): the hidden value both are trying to track.
  • Rewards: what the agent actually sees.
  • Sample average, step size $\tfrac{1}{n}$ (Lesson 6).
  • Constant step size $\alpha$.

The maths

Replace $\tfrac{1}{n}$ with a fixed $\alpha \in (0, 1]$:

$$Q_{n+1} = Q_n + \alpha\,\big[R_n - Q_n\big] = \alpha R_n + (1-\alpha)\,Q_n$$

The new estimate is a share $\alpha$ of the newest reward plus a share $1-\alpha$ of the old estimate. Substitute the same rule for $Q_n$, then for $Q_{n-1}$, and so on:

$$\begin{aligned} Q_{n+1} &= \alpha R_n + (1-\alpha)\big[\alpha R_{n-1} + (1-\alpha)\,Q_{n-1}\big] \\ &= \alpha R_n + \alpha(1-\alpha) R_{n-1} + (1-\alpha)^2 Q_{n-1} \\ &= (1-\alpha)^n\, Q_1 + \sum_{i=1}^{n} \alpha (1-\alpha)^{n-i}\, R_i \end{aligned}$$

Reward $R_i$ gets weight $\alpha(1-\alpha)^{n-i}$. The newest ($i = n$) gets $\alpha$, the next $\alpha(1-\alpha)$, and each step further back multiplies the weight by another $(1-\alpha)$. This is an exponential recency-weighted average. The weights, including $(1-\alpha)^n$ on the starting guess $Q_1$, add up to 1, and the starting guess fades away.

The sample average instead gives every reward the same weight, $\tfrac{1}{n}$. A reward from step 1 counts as much as the latest one. That is right when $q_*$ is fixed, because every reward is equally good evidence. When $q_*$ moves it is wrong: old rewards describe where the target used to be, and with equal weights they keep outvoting the new ones. Constant $\alpha$ fixes this by letting old rewards fade.

The cost: a constant $\alpha$ never fully settles, because every new reward still nudges it. Lessons 45 and 52 come back to when a step size settles.

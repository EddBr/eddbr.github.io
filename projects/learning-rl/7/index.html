Step sizes and moving targets

A restaurant gets a new chef. A slot machine is quietly re-tuned. When the true value changes over time, an average of everything since the start falls behind. Replacing $\tfrac{1}{n}$ with a constant step size $\alpha$ fixes this.

The maths

Replace $\tfrac{1}{n}$ with a fixed $\alpha \in (0, 1]$:

$$Q_{n+1} = Q_n + \alpha\,\big[R_n - Q_n\big]$$

Unrolling the recursion shows how much each reward counts:

$$Q_{n+1} = (1-\alpha)^n\, Q_1 + \sum_{i=1}^{n} \alpha (1-\alpha)^{n-i}\, R_i$$

The weight on a reward shrinks by a factor $(1-\alpha)$ for every newer reward. This is an exponential recency-weighted average. The weights sum to 1, the initial guess $Q_1$ fades away, and recent rewards matter most.

The trade-off: a constant $\alpha$ never settles down, because every new reward keeps nudging it. Stochastic approximation theory says an estimate converges for sure only if the step sizes $\alpha_n$ satisfy

$$\sum_{n=1}^{\infty} \alpha_n = \infty \qquad \text{and} \qquad \sum_{n=1}^{\infty} \alpha_n^2 < \infty$$

The first condition means steps stay big enough to overcome any starting error. The second means they eventually shrink enough to stop the noise. $\tfrac{1}{n}$ satisfies both. A constant $\alpha$ fails the second, which is exactly what lets it keep tracking a moving target.

Discounting

A reward now is usually worth more than the same reward later. RL agents multiply each future reward by $\gamma$ (gamma) for every step they have to wait.

Value of a reward of 1 that arrives $k$ steps from now: $\gamma^k$

The maths

The discounted return from time $t$:

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

with $0 \le \gamma \le 1$. Small $\gamma$ makes the agent short-sighted. $\gamma$ near 1 makes it far-sighted.

If every reward is 1 and $\gamma < 1$, the return is a geometric series with a finite sum:

$$1 + \gamma + \gamma^2 + \dots = \frac{1}{1-\gamma}$$

The return also has a recursive form. Pull out the first reward and what remains is $\gamma$ times the next return:

$$G_t = R_{t+1} + \gamma\, G_{t+1}$$

This one line becomes the Bellman equation in Unit 6.

Why discount? The future is uncertain, the maths stays finite, and people and animals prefer rewards sooner. From an action's point of view, a reward $k$ steps later counts only $\gamma^k$ towards it.

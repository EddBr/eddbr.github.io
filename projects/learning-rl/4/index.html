Discounting

A reward you have to wait for counts for less. The first reward counts in full, and each reward after it is multiplied by $\gamma$ (gamma) once more.

In Lesson 2 the robot just added up its rewards, so with no step cost the gem (5) beat the coin (1) however far away it was. $\gamma = 1$ gives you those same sums. Slide it down until the robot changes its mind.

Gem → (4 steps)

The gem is four steps away but gets $\gamma^3$, because it arrives three steps after the first reward. The first reward is never discounted.

What if the rewards never stop?

The coin and the gem each pay out once. Now imagine a robot that earns +1 on every step, with no end. Just adding up gives $1 + 1 + 1 + \dots$, which grows forever, so two endless options can't be compared. Each bar shows what one of those +1s counts for after discounting.

The maths

The discounted return from time $t$:

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

with $0 \le \gamma \le 1$. Small $\gamma$ makes the agent short-sighted. $\gamma$ near 1 makes it far-sighted.

The sum starts at $k = 0$, so $R_{t+1}$ gets no $\gamma$ even though it takes a step to arrive. Only the gaps between rewards matter: multiplying every reward by one more $\gamma$ would shrink every return by the same factor, so the best choice would stay the same.

If every reward is 1 and $\gamma < 1$, the return is a geometric series with a finite sum:

$$1 + \gamma + \gamma^2 + \dots = \frac{1}{1-\gamma}$$

The return also has a recursive form. Pull out the first reward and what remains is $\gamma$ times the next return:

$$G_t = R_{t+1} + \gamma\, G_{t+1}$$

This one line becomes the Bellman equation in Unit 6.

Why discount? The future is uncertain: you can read $\gamma$ as the chance the world carries on for one more step. Discounting also keeps the maths finite, and people and animals prefer rewards sooner.

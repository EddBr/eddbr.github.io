SARSA

TD(0) learned state values. To choose actions without a model, the agent needs action values $Q(s, a)$. SARSA applies the TD update to them, using the action the agent actually takes next. Learning and acting happen in the same loop, so the policy improves during the episode.

The maths

SARSA is TD(0) with the state value $V(S_t)$ replaced by the action value $Q(S_t, A_t)$:

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha\big[R_{t+1} + \gamma\, Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t)\big]$$

Each update uses five things, $(S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1})$, which give the method its name. $A_{t+1}$ is chosen by the policy before the update, and it is the action the agent then takes. If $S_{t+1}$ is terminal, $Q(S_{t+1}, \cdot) = 0$.

Why this target: the Bellman equation for action values (Lesson 22, Lesson 26) is

$$q_\pi(s, a) = \mathbb{E}_\pi\big[R_{t+1} + \gamma\, q_\pi(S_{t+1}, A_{t+1}) \,\big|\, S_t = s, A_t = a\big]$$

The SARSA target is one sample of the quantity inside the expectation, with $Q$ in place of $q_\pi$. So SARSA estimates $q_\pi$ for the policy $\pi$ it is following. This makes it on-policy.

The policy is ε-greedy with respect to the current $Q$. As $Q$ changes, the policy changes with it: evaluation and improvement interleave on every step, which is generalised policy iteration (Lesson 34). The probability of the greedy action, with $|\mathcal{A}|$ actions, is

$$\pi(a_\text{greedy} \mid s) = 1 - \varepsilon + \frac{\varepsilon}{|\mathcal{A}|}$$

The ε-greedy share of exploration is spread over all actions, including the greedy one. SARSA converges to $q_*$ and an optimal policy with probability 1 if every state–action pair is visited infinitely often and the policy becomes greedy in the limit (for example $\varepsilon_t = 1/t$), with suitably decreasing step sizes.

Why not Monte Carlo here: some policies never reach G (for example, always pushing into a wall). Monte Carlo cannot update until an episode ends, so it can get stuck. SARSA learns within the episode that the stuck action is bad (each step costs $-1$) and switches to another one.

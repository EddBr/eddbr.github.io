Reward hacking

An agent maximises the reward it is given, not the goal its designer had in mind. When the two differ, the agent finds the gap and exploits it. This is called reward hacking or specification gaming.

Lesson 2's corridor, with one change: the coin respawns as soon as the robot steps off it. The designer wants the robot to reach the gem. The coin was meant as a small hint.

The maths

The robot starts in cell 1, next to the coin. Stepping onto the coin pays $c$. Stepping back off pays 0, and the coin reappears. Repeating forever gives the return

$$\begin{aligned} G_{\text{coin}} &= c + \gamma \cdot 0 + \gamma^2 c + \gamma^3 \cdot 0 + \dots \\ &= c \sum_{k=0}^{\infty} \gamma^{2k} = \frac{c}{1 - \gamma^2} \end{aligned}$$

A geometric series in $\gamma^2$, because a coin arrives every second step. Walking to the gem takes 4 steps and pays $g$ on the last one:

$$G_{\text{gem}} = \gamma^3 g$$

The agent farms the coin whenever

$$\frac{c}{1 - \gamma^2} > \gamma^3 g$$

With $c = 1$ and $\gamma = 0.9$ the loop is worth $5.26$ and the gem $0.729\,g$, so any gem below about $7.2$ loses. As $\gamma \to 1$ the loop is worth unbounded reward and no finite gem can compete.

The agent is not broken. It has found the optimal policy for the reward it was given. The bug is in the reward: the designer's goal was "reach the gem", and the coin was a proxy that agreed with that goal only until the agent learned to exploit it.

A hint that cannot be farmed has a specific form. Ng, Harada and Russell (1999) showed that a potential-based shaping reward $F(s, s') = \gamma \Phi(s') - \Phi(s)$, for any function $\Phi$ of the state, never changes which policy is optimal. Along any trajectory it telescopes:

$$\begin{aligned} &\sum_{t=0}^{T-1} \gamma^t \big(\gamma \Phi(S_{t+1}) - \Phi(S_t)\big) \\ &\quad = \gamma^T \Phi(S_T) - \Phi(S_0) \end{aligned}$$

The total bonus depends only on where the trajectory starts and ends, so walking in a circle earns nothing. A respawning coin is not of this form: every lap pays $c$ again.

Real examples are collected in Krakovna et al.'s list. In one, a boat-racing agent in the game CoastRunners learned to circle a lagoon hitting the same respawning targets instead of finishing the race (OpenAI, 2016). Lesson 2's cleaning robot that dumps dirt to pick it up again is the same bug.

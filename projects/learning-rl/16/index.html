Markov chains

A Markov chain is a set of states plus a table saying how likely each state is to follow each other one. There are no actions and no rewards yet: the world just moves. It is the skeleton that an MDP (Lesson 18) adds actions and rewards to.

The maths

A Markov chain is a set of states $\mathcal{S}$ and a transition matrix $P$ with entries

$$P_{ss'} = P(S_{t+1} = s' \mid S_t = s)$$

Row $s$ is the forecast for tomorrow when today is $s$. Every entry is between 0 and 1 and every row sums to 1, because tomorrow has to be something:

$$\sum_{s'} P_{ss'} = 1 \quad \text{for every } s$$

Two steps ahead. To go from $s$ to $s'$ in two days, pass through some $k$ on the way. Add up every route:

$$P(S_{t+2} = s' \mid S_t = s) = \sum_{k} P_{sk}\, P_{ks'} = (P^2)_{ss'}$$

The sum over $k$ is exactly how matrix multiplication works, so $n$ steps ahead is the matrix power $P^n$.

A distribution moves the same way. Write $\mu_t$ for the row vector of probabilities of each state on day $t$. Then

$$\mu_{t+1}(s') = \sum_s \mu_t(s)\, P_{ss'}$$

The probability of $s'$ tomorrow is the sum over today's states of "be in $s$" times "move from $s$ to $s'$". In matrix form, $\mu_{t+1} = \mu_t P$, so $\mu_t = \mu_0 P^t$. Starting surely in state $s$ means $\mu_0$ is 1 at $s$ and 0 elsewhere, and then $\mu_t$ is just row $s$ of $P^t$.

How long a spell lasts. Staying in $s$ has probability $P_{ss}$ each day, so a spell lasts $k$ days with probability $P_{ss}^{\,k-1}(1 - P_{ss})$. That is a geometric distribution with mean $1/(1 - P_{ss})$.

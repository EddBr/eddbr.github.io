Reward models

Lesson 86 gave a score to five fixed answers. RL needs a score for any answer the policy might write, including ones no person has seen. A reward model is a function fitted to the comparisons with the Bradley–Terry loss, so it can score new answers. It learns whatever the raters reward, biases included.

Each dot is an answer, placed by two features: how correct it is and how long it is. The maths

A reward model $r_\phi(x, y)$ maps a prompt $x$ and a reply $y$ to a number. The data is a set $\mathcal{D}$ of triples $(x, y_w, y_l)$: a prompt, the preferred reply and the other one. Bradley–Terry (Lesson 86) with $r_\phi$ in place of a table of scores gives the loss (Ouyang et al. 2022, eq. 1)

$$\begin{aligned} \mathcal{L}(\phi) = -\,\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}}\Big[&\log \sigma\big(r_\phi(x, y_w) \\ &\;- r_\phi(x, y_l)\big)\Big] \end{aligned}$$

It is the negative log-likelihood of the observed choices. A pair the model already orders confidently costs almost nothing; a pair it orders the wrong way costs a lot.

Gradient. Write $\Delta = r_\phi(x, y_w) - r_\phi(x, y_l)$. Since $\frac{d}{d\Delta}\big(-\log\sigma(\Delta)\big) = -(1 - \sigma(\Delta))$,

$$\begin{aligned} \nabla_\phi \mathcal{L} = -\,\mathbb{E}\Big[&\big(1 - \sigma(\Delta)\big) \\ &\times\big(\nabla_\phi r_\phi(x, y_w) - \nabla_\phi r_\phi(x, y_l)\big)\Big] \end{aligned}$$

Descent raises the winner's score and lowers the loser's, weighted by how surprised the model was. For the linear model on this page, $\nabla_{\mathbf w} r = \mathbf f$ (the feature vector), so this is logistic regression on feature differences $\mathbf f_w - \mathbf f_l$. A constant term would cancel in $\Delta$, so there is no bias: scores are only defined up to a shift, as before.

In practice $r_\phi$ is a copy of the language model with its next-token layer replaced by a single number read at the last token. It is trained on tens or hundreds of thousands of comparisons, and its output becomes $R$ in Lesson 85's MDP.

It learns the raters, not the truth. If raters favour longer answers, a well-fitted reward model does too, and so does any policy optimised against it. Push $b$ up and the long, wrong answer outscores the short, right one. Lesson 88 limits how hard a policy can push on these flaws.

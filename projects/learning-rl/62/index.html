Gradient descent on values

Lesson 61 found the best weights by solving equations that need the true values. An agent only sees returns. Stochastic gradient descent uses each return to nudge the weights a little way downhill on the value error, and the nudges add up to the best fit.

The 1000-state walk again, with two features: $\mathbf{x}(s) = (1, z)$ where $z$ runs from $-1$ at state 1 to $+1$ at state 1000. So $\hat v(s,\mathbf{w}) = w_1 + w_2 z$ is a straight line.

The maths

The goal is to minimise the value error from Lesson 61, $\overline{\text{VE}}(\mathbf{w}) = \sum_s \mu(s)[v_\pi(s) - \hat v(s,\mathbf{w})]^2$. States arrive with distribution $\mu$, so one state $S_t$ gives a one-sample estimate of it. Stepping against that sample's gradient is stochastic gradient descent (S&B eq. 9.4–9.5):

$$\begin{aligned} \mathbf{w}_{t+1} &= \mathbf{w}_t - \tfrac{1}{2}\alpha \nabla \big[v_\pi(S_t) - \hat v(S_t,\mathbf{w}_t)\big]^2 \\ &= \mathbf{w}_t + \alpha \big[v_\pi(S_t) - \hat v(S_t,\mathbf{w}_t)\big] \nabla \hat v(S_t,\mathbf{w}_t). \end{aligned}$$

The $\tfrac12$ cancels the 2 from the chain rule. Each step moves the weights in the direction that most reduces this state's error.

The agent does not know $v_\pi(S_t)$, so it uses a target $U_t$ in its place:

$$\mathbf{w}_{t+1} = \mathbf{w}_t + \alpha \big[U_t - \hat v(S_t,\mathbf{w}_t)\big] \nabla \hat v(S_t,\mathbf{w}_t).$$

If $\mathbb{E}[U_t \mid S_t] = v_\pi(S_t)$, the step is right on average, and with step sizes that shrink in the usual way ($\sum \alpha_t = \infty$, $\sum \alpha_t^2 < \infty$) $\mathbf{w}$ converges to a local minimum. The return $G_t$ qualifies, which gives gradient Monte Carlo. For a linear $\hat v$, $\nabla \hat v = \mathbf{x}(S_t)$ and $\overline{\text{VE}}$ is a bowl with one minimum, so local means global.

One update changes the estimate at $S_t$ itself by

$$\hat v(S_t, \mathbf{w}_{t+1}) - \hat v(S_t, \mathbf{w}_t) = \alpha \big[G_t - \hat v(S_t,\mathbf{w}_t)\big]\, \lVert \mathbf{x}(S_t) \rVert^2 .$$

So $\alpha \lVert \mathbf{x} \rVert^2$ is the fraction of the error removed at that state. Every other state moves too, by $\alpha [G_t - \hat v]\, \mathbf{x}(S_t)^\top \mathbf{x}(s)$.

Using a bootstrapped target such as $U_t = R_{t+1} + \gamma \hat v(S_{t+1}, \mathbf{w}_t)$ breaks the condition twice: its expectation is not $v_\pi(S_t)$, and it depends on $\mathbf{w}_t$ while the update ignores that dependence. S&B call this a semi-gradient method. Linear semi-gradient TD(0) still converges on-policy (S&B §9.4), to the TD fixed point rather than the minimum of $\overline{\text{VE}}$. Lesson 65 shows how it can fail off-policy.
